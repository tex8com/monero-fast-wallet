# Security and release status

This source repository is public-development material. It is not a statement
that any build is approved for production mainnet use or real funds.

Before any production release, the project requires at least:

- reproducible, signed release artifacts;
- physical iOS, Android, desktop and Ledger validation where supported;
- recovery, update and operational testing;
- an independent security review of the relevant release scope; and
- a clean dependency, license and secret-scanning review.

Report vulnerabilities through the process in the root
[SECURITY.md](../SECURITY.md). Do not disclose active vulnerabilities or any
wallet secret in a public issue or pull request.
