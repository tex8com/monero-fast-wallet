# CUDA benchmark results — July 25–26, 2026

## Measurement definition

Monero’s wallet derivation `generate_key_derivation(8 * view_secret_key,
tx_public_key)` is measured for a constant secret scalar and many different
public points. GPU time is measured with CUDA events. All runs listed as valid
ended with `validation=pass` and the expected result checksum.

Reference for all acceleration factors is the median of the unchanged
Monero-Ref10 single-thread implementation:

```text
27,030.166 derivations/s = 1.00x
```

| GPU and measurement | Variant | Derivatives/s | Factor to Ref10 |

| RTX 5090, C11 formal median | Radix-4, six runs | 26,646,642.758 | 985.81x |
| RTX 5090, C8/LB5 formal median | Launch Bounds, six runs | 26,811,990.634 | 991.93x |

The RTX 5090 was 2.369 times faster on the best single run than the best
RTX-3090 single run. When comparing the continuous runs C7/5090 against C6/3090,
the factor was 2.491.

### Launch Bounds

C8/LB5 and C9/LB6 reduce the register number to 168, but generate 600 byte
stack, 756 byte spill stores and 1,320 byte spill loads per thread.

| Measurement | Derivatives/s |
| --- | ---: |
| C8/LB5 short sample run | 27,320,958.865 |
| C9/LB6 short sample run | 27,274,174.126 |
| C8/LB5, 32 threads, best single run | **27,323,459.974** |
| C8/LB5, 64 threads | 27,272,828.442 |
| C8/LB5, formal median | 26,811,990.634 |
| C8/LB5 Endurance | 26,852,358.544 |
| C7 Continuous running for comparison | **26,877,688.327** |

The small advantage of the short LB5 runs disappeared in continuous running. C7
therefore remains the robust final variant.

| Compression | 72 | 0 B | 0 B | 0 B |

On SM 12.0, 255 registers per thread limit the theoretical occupancy to eight
active warps or around 16.7 percent. Nsight Compute could not read the hardware
counter of the rental system due to `ERR_NVGPUCTRPERM`. The resource information
is taken from `nvcc -Xptxas=-v`.
