# Desktop languages

The desktop wallet starts in the device language (German or English) and
remembers the user's choice locally under `tex8-monero-language`. It never
sends a language preference to a node, Ledger, or community service.

All user-facing desktop phrases belong in `src/i18n.tsx`. Add another language
by extending `LanguageCode` and adding the same key set below `messages`. The
TypeScript build fails when a key is missing, so an incomplete translation
cannot silently reach a release build.

Use the hook in a screen or component:

```tsx
const { t } = useI18n();
return <h2>{t('send.title')}</h2>;
```

Use named placeholders for data that belongs in a sentence:

```tsx
t('home.lock', { name: walletName });
```

Addresses, transaction hashes, ledger prompts, and amounts remain native data
and are deliberately not translated.
